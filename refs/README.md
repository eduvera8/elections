# refs/

PDFs of papers go here. They are gitignored — don't commit copyrighted articles to a public
repository.

The reading list, with what each item does and whether it has been read, lives in
`docs/04-literature.md`. Keep that file current; it is the part that is actually shared.

Start with De la Calle (2024), *Electoral Studies* 90:102827 — open access under CC BY, so
copies at Warwick WRAP (eprint 190657) or White Rose (eprint 233457) are freely distributable.
