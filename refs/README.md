# refs/

PDFs of papers go here. They are gitignored — don't commit copyrighted articles to a public
repository.

The reading list, with what each item does and whether it has been read, lives in
`docs/04-literature.md`. Keep that file current; it is the part that is actually shared.

De la Calle (2024), *Electoral Studies* 90:102827, is the exception: it sits **committed at the
repository root** as `1-s2.0-S0261379424000854-main.pdf`, where it was uploaded. It is open
access under CC BY, so redistributing it is explicitly permitted and keeping it in the repo is
fine. Reading notes are in `docs/06-delacalle-2024-notes.md`.
